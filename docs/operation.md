# 操作与当前参数

## 轮位与方向

CAN ID 1=左后，2=左前，3=右前，4=右后；反馈帧0x201～0x204，电流组帧0x200。四轮统一从底盘中心沿轮轴向外看，顺时针为编码器正方向。

俯视实测：SB上档原始值460 → 整车逆时针 → 原始陀螺Z为正 → 四轮公共原始rpm为负。混控旋转项因此为负号，不能从电机rpm正号直接推断整车旋向。

## 遥控

| 输入 | 功能 | 停车区 |
|---|---|---|
| 左手前后CH2 | 参考系前后移动 | 中心820，670～970 |
| 左手左右CH4 | 参考系左右移动 | 中心1024，死区±150 |
| SB/CH3 | 双向自旋，保持平移参考航向 | 中档约1024 |
| 右手左右CH1 | 转向并更新平移参考航向 | 中心1024，死区±150 |

左手前后油门不自回中。SB回中只取消自旋，平移油门也要回停车区。上电、失联恢复或清故障后，运动通道全回中连续500ms才解锁。

约0.63秒加满、0.31秒降零是指令斜坡时间，实际起停受负载、电流限幅和轮地接触影响。死区也会减少实际遥控满杆对应值。

几何参数在main.c：轮半径0.075m、半长0.150m、半宽0.160m、减速比约19.2032。几何仍为初值。

预测仅调整有平移请求时的混控角，不改变参考航向，不为全零输入制造动作，实际停转后补偿量归零。默认关闭航向保持纠偏。
