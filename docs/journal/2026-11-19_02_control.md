# 遥控与控制修复

## 问题与处理

- 航向保持开关曾未约束实际纠偏路径，回中仍可能动作；默认关闭纠偏，保留参考坐标变换。
- 全零目标使用实际轮速主动制动，最长1200ms；超时锁存F_STOP_TIMEOUT。
- 手动停车优先；TELEOP不得覆盖已锁存故障。
- SBUS处理8E2、错误字节、帧尾和失控标志；单帧丢失最多保留上一有效命令200ms。
- 同一SBUS帧复制通道/标志/时间戳，避免帧龄误判；恢复后全回中500ms解锁。
- 右摇杆单独更新平移参考航向；SB自旋不更新参考。
- 减速过渡的相对超速阈值逐渐收紧，保留持续异常与9000rpm硬超速锁存。

## 参数演进

平移映射300→450mm/s；SB最终目标12566mrad/s。加减速斜率最终为20000/40000mrad/s²，指令约0.63/0.31秒。遥控电流限幅2457，目标转子上限8000rpm。

## 验证

主机回归覆盖混控、场地变换、参考航向、SB斜坡、故障锁存、全零制动、减速/过零和记录器边界。现场曾确认两个旋向、自旋叠加平移和停车。不同版本的具体验收证据分开保存，不把全部历史记录合并成“全程无故障”。
