# 已知限制

1. 轮径150mm来自用户测量，半长/半宽仍是估计值；尚无外部定位量化轨迹。
2. 30ms预测前后的有效样本分别为逆时针和顺时针，不能宣称完成同条件双向A/B验收。用户结束调试，待命的反向复核已取消。
3. 用户对第一次补偿后的主观反馈为“感觉差不多”，随后表示当前可以使用；编码器估计的改善不等于已证明地面轨迹同幅改善。
4. 高速混合运动中1号/3号轮出现部分电流触限。预测修正相位，不会消除所有电机动态误差。
5. BMI088加速度读取保留历史实现，其中Z高字节屏蔽符号位的问题尚待修复/验证；当前航向控制使用陀螺Z，不依赖该加速度值。
6. 备用USART1 ASCII通路未完成本轮硬件验收，GPIO初始化模式仍需核对。Web串口页面、USB CDC原型和历史PWM/DBUS诊断不作为已验收功能。
7. Horco v0.2存在首条DAP命令不应答及偶发读回错误；工具保留热身、独占访问、双读一致和失败退出，不能据此宣称烧录零风险。
8. 整理后源码已通过主机测试和构建，但未再次部署到板上；当前板上固件与本地新构建的SHA256分别记录。

9. deploy.py的历史--restore-listener选项依赖本机兄弟监听工程；公共仓库的标准部署使用--env，不依赖该路径。
